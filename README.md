# mind-trace
Приложение нацелено на обучение человека за счет активного повторения по кривой забывания.
Таким образом человек развивает свой навык речи и активно запоминает информацию, которую он узнал.
Приложение предоставляет как голосовой режим, так и текстовый.
Источник знаний - человек.
Сделав заметку, человек по напоминаю приложения проходит и начинает диалог в чате. 
Проверяющим выступает - ИИ, но не источником информации. Задает вопросы по конспекту человека.
По итогам приводит оценку диалога и аспекты, которые человек не понял до конца.

Транскрибация будет происходить через микросервис на питоне. Конспекты/заметки человека - база знаний.
